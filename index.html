todoki
使い方 サポート 利用規約 プライバシー

URL を叩くだけで、
スマホに通知が届く。

todoki は、発行された Webhook URL に HTTP POST するだけでスマホにプッシュ通知が届くサービスです。アカウント登録なし、SDK なし。curl 1 行から始められます。

curl -X POST "$TODOKI_URL" \
  -H 'content-type: application/json' \
  -d '{"title":"デプロイ完了","body":"v1.2.3 を本番反映"}'

使い方は 3 ステップ

  1. アプリを入れる — todoki アプリをインストールして起動するだけ。ログインは不要です。
  2. URL を発行する — アプリ内で通知用の URL を発行し、コピーします。URL は用途ごとに何本でも作れます。
  3. POST する — CI・サーバ・スクリプトなど、HTTP を話せるものならどこからでも。届いた通知はアプリが受け取ります。

こんな用途に

  • CI のビルド結果・デプロイ完了の通知
  • サーバ監視・バッチ処理の異常検知アラート
  • 自作スクリプト・IoT デバイスからのお知らせ
  • 長時間処理の「終わったよ」通知

特徴

  • 摩擦ゼロ — アプリを入れた瞬間から使える。アカウント作成・メール認証なし。
  • URL がそのまま秘密鍵 — 推測不能なランダム URL。漏れたらアプリからワンタップで再発行（旧 URL は即失効）。
  • 柔軟な payload — JSON でタイトル・本文・タップ時に開く URL・優先度を指定。プレーンテキストを投げるだけでも OK。
  • URL ごとのテンプレート — 送信側はサービスの生 JSON を送るだけ。通知の見た目は URL 側の設定で整形。
