よくある質問

通知が届きません
  • iOS の「設定 > 通知 > todoki」で通知が許可されているか確認してください。
  • アプリ内で該当 URL がミュート（OFF）になっていないか確認してください。
  • URL を再発行した場合、旧 URL は失効しています。送信側に新しい URL を設定し直してください。
  • 集中モード（おやすみモード）中は通知の表示が抑制されることがあります。
途絶監視（ハートビート）— 通知が来すぎる / 来ない / 出したくない

途絶監視は、その URL が一定時間 POST されなかったこと（沈黙）を検知して知らせる機能です。アプリの URL 詳細画面で、URL ごとに「途絶を監視」を ON にできます。

  • 途絶通知を出したくない — 設定した監視間隔の内に、最低 1 回その URL へ POST してください（普段の通知 POST も心拍としてカウントされます）。
  • 何度も来る — 1 回の途絶につき最大 4 通（途絶 1 + 追い通知 2 + 復帰 1）で打ち止めです。鳴り続けることはありません。間隔が短すぎる場合は長めに設定し直してください。
  • 来ない — その URL がミュート（OFF）だと、途絶通知も届きません（アプリ内の「途絶」バッジだけが付きます）。

詳しくは 使い方の途絶監視（ハートビート） を参照してください。

URL が漏れたかもしれません

アプリの該当 URL から「再発行」してください。旧 URL は即座に無効になり、以後の送信は 410 で拒否されます。送信側には新 URL を設定し直してください。

機種変更・再インストールでデータは引き継げますか？

機種変更・端末の初期化ではデータは引き継げません（外部アカウント連携による引き継ぎ機能は今後提供予定です）。アプリを削除した場合、通知履歴は失われます（URL は通常復元されますが保証はありません）。履歴は「設定 > 履歴を書き出す」でバックアップできます。

Android 版はありますか？

現在は iOS のみ提供しています。Android 版は今後の対応を予定しています。
