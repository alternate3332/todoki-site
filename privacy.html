プライバシーポリシー

鈴木智博（以下「運営者」）は、プッシュ通知サービス「todoki」（以下「本サービス」）における利用者の情報の取り扱いについて、以下のとおり定めます。

1. 取得する情報

情報取得のタイミング・内容
デバイストークンアプリの初回起動時等に、プッシュ通知の配信先識別子（Apple が発行する APNs デバイストークン）を取得します。
匿名識別子初回起動時に、本サービスがランダムに発行する利用者識別子（特定の個人を直接識別しないもの）。
通知の内容利用者（またはその指示で動くシステム）が Webhook URL に送信したデータ。通知の組み立て・配信のために処理します。
外部アカウント情報任意で Google・LINE 等と連携した場合に限り、当該サービスから提供されるアカウント識別子等。データ引き継ぎのためにのみ使用します。
利用記録API へのアクセス記録（リクエスト日時、送信元 IP アドレス、処理結果等のサーバログ）。

本サービスは、氏名・住所・電話番号等の入力を求めません。広告 ID の取得や、広告目的のトラッキングは行いません。

2. 利用目的

  1. プッシュ通知の配信（本サービスの提供そのもの）
  2. 不正利用・異常な利用パターンの検知と、サービスの安定運用
  3. 障害調査・問い合わせ対応
  4. 機種変更・再インストール時のデータ引き継ぎ（外部アカウント連携時のみ）

3. 通知内容の取り扱いについて

Webhook URL に送信されたデータは、通知の配信のために処理され、障害調査・不正利用対策のためサーバの運用ログに一定期間記録されます。機密性の高い情報（パスワード、認証トークン等）を通知の本文に含めないことを推奨します。

4. 第三者提供・委託

  1. 運営者は、法令に基づく場合を除き、取得した情報を第三者に提供しません。
  2. 本サービスの提供のため、以下の外部サービスにデータの処理を委託しています。
    • Amazon Web Services（サーバ基盤。データは日本国内のリージョン（東京）に保存）
    • Apple Push Notification service（iOS へのプッシュ通知配信。通知内容が Apple のサーバを経由します）
  3. 外部アカウント連携を利用した場合、認証の過程で Google・LINE 等の各社プライバシーポリシーが適用されます。

5. 保存期間

  1. デバイストークン・匿名識別子・URL の設定情報は、利用者が削除（URL の失効、アカウントの削除）するまで保存します。
  2. サーバの運用ログ（通知内容の記録を含む）は、運用上必要な一定期間の経過後に削除します。

6. 安全管理

運営者は、取得した情報への不正アクセス、漏えい、滅失を防ぐため、通信の暗号化（TLS）、アクセス制御、認証情報の安全な保管等、合理的な安全管理措置を講じます。

7. 利用者の権利

  1. 利用者は、アプリから URL の失効・データの削除を行うことができます。
  2. 取得した情報の開示・訂正・削除等を希望される場合は、下記の連絡先までお問い合わせください。本サービスの性質上、匿名識別子のみで利用されている場合、本人確認のために追加の情報（対象の URL 等）の提示をお願いすることがあります。

8. 改定

本ポリシーは、法令の変更やサービスの変更に応じて改定されることがあります。重要な変更の場合は、アプリ内の表示等の合理的な方法で周知します。
